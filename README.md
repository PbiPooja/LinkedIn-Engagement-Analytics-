# LinkedIn-Engagement-Analytics-
LinkedIn Engagement Analytics project built in SQL Server using advanced Window Functions to analyze creator engagement, growth trends, rankings, and business KPIs.

## Functions Used-

- SQL Server
- Window Functions
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()
- LEAD()
- NTILE()
- Running Totals
- Moving Averages

## Business KPIs solved

1. Rank creators by engagement
2. Calculate engagement growth
3. Compare current vs previous performance
4. Build creator leaderboards
5. Segment creators into quartiles
6. Calculate contribution percentages
7. Analyze engagement trends
